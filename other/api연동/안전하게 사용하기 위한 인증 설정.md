# 인증

<TenantName /> API Gateway를 안전하게 사용하기 위한 인증 설정을 안내합니다.

하나의 API 키로 모든 AI 모델에 접근할 수 있으며, OpenAI SDK와 Anthropic SDK 모두 별도의 헤더 설정 없이 바로 사용할 수 있도록 두 가지 인증 방식을 지원합니다.

아래 가이드를 따라 빠르게 설정해보세요!

<Indent mt={12} />

## API 키 발급

1. <TenantName /> 웹사이트에 로그인해주세요.
2. 좌측 하단의 **API Gateway** 버튼을 클릭해주세요.
3. **API 키 생성** 버튼을 클릭하여 키를 발급해주세요.
4. 생성된 API 키를 복사하여 안전한 곳에 보관해주세요.

<Banner variant="info">
  API 호출 시 크레딧은 API 키를 생성한 계정에서 차감됩니다.
</Banner>

<Banner variant="warning">
  생성된 키는 다시 조회할 수 없습니다. 보안을 위해 반드시 안전한 곳에 보관해주세요.
</Banner>

---

## 지원되는 헤더 방식

### 방법 1: Authorization Bearer (OpenAI SDK 기본)

```http
Authorization: Bearer YOUR_API_KEY
```

OpenAI Python/JS SDK에서 기본으로 사용됩니다.

### 방법 2: x-api-key (Anthropic SDK 기본)

```http
x-api-key: YOUR_API_KEY
```

Anthropic Python/JS SDK 및 Claude Code CLI에서 기본으로 사용됩니다.

두 방식 모두 완전히 지원되므로, 표준 SDK 사용 시 별도의 헤더 설정이 필요하지 않습니다.

## 환경 변수 패턴

### OpenAI SDK

```bash
export OPENAI_API_KEY=YOUR_API_KEY
export OPENAI_BASE_URL=https://factchat-cloud.mindlogic.ai/v1/gateway
```

### Anthropic SDK / Claude Code

```bash
export ANTHROPIC_BASE_URL=https://factchat-cloud.mindlogic.ai/v1/gateway/claude
export ANTHROPIC_AUTH_TOKEN=YOUR_API_KEY
```

<Banner variant="info">
  Claude Code에서 커스텀 Base URL을 설정할 때는 `ANTHROPIC_API_KEY`가 아닌 `ANTHROPIC_AUTH_TOKEN`을 사용해야 합니다.
</Banner>

## 보안

<Banner variant="warning">
  API 키 보안을 위해 다음 사항을 반드시 지켜주세요:

  - API 키는 항상 환경 변수에 저장하고, 소스 코드에 직접 포함하지 마세요
  - HTTPS 엔드포인트만 사용하세요 (HTTP는 지원되지 않습니다)
  - 키가 노출되었다면 즉시 API Gateway 페이지에서 해지하고 새 키를 발급받으세요
</Banner>

- API 키는 조직별로 범위가 지정됩니다 — 다른 조직의 모델에 접근할 수 없습니다
- 키는 API Gateway 페이지에서 언제든지 해지할 수 있습니다
