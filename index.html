  2. 2

    조건이 맞는 정책을 됩니다 / 확인 필요 로 나눠 보여 드립니다.

조건별 판정

    준비할 서류

      신청 기한

      확인할 곳

      이 화면은 예시 정책 데이터로 만든 참고 결론입니다. 실제 지원 자격·서류·기한은 담당 기관 공고 원문에서 반드시 확인하세요.

      이용 안내

      이렇게 쓰면 됩니다

      1. 시작하기를 누르고 여덟 개 질문에 답합니다. 한 화면에 한 질문만 나옵니다.
      2. 결과에서 됩니다 / 확인 필요로 나뉜 정책 목록을 봅니다.
      3. 정책을 누르면 조건별 판정, 준비 서류, 신청 기한을 확인합니다.
      4. 글씨가 작으면 오른쪽 위 가 버튼으로 크기를 키웁니다.

      하지 않는 것

      • 최종 자격을 확정하지 않습니다. 됩니다 / 안됩니다는 참고 결론입니다.
      • 고른 답만 봅니다. 서류 심사나 예산 소진 여부는 알 수 없습니다.
      • 답변은 브라우저를 벗어나지 않으며 어디에도 저장하지 않습니다.
